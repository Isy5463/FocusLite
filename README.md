# FocusLite – Chirurgischer Doomscroll-Blocker (Android)

## Schnellstart: Automatisch als APK bauen lassen (über GitHub Actions)
1. Entpacke diese ZIP-Datei auf deinem PC.
2. Erstelle auf [GitHub](https://github.com/new) ein neues (privates) Repository.
3. Lade den gesamten Inhalt dieses Ordners (inklusive des `.github`-Ordners!) in das Repository hoch.
4. Klicke in deinem GitHub-Repository oben auf den Reiter **Actions**.
5. Nach ca. 2–3 Minuten ist der Workflow **Build FocusLite APK** grün. Klicke darauf und lade ganz unten unter **Artifacts** die Datei **FocusLite-Debug-APK** herunter.
